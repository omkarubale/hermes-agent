Z2-1 Hermes

A personally operated AI assistant running on its owner's home server.

What it does

Z2-1 Hermes answers the owner's requests through a connected chat interface. The owner has connected Google Calendar so Hermes can read, create, update, and delete events on calendars they own when asked. Calendar access is provided by Google's OAuth service.

Data and privacy

Calendar details and conversation content are handled by the home server and the model services selected in the owner's configuration. The current model route may send relevant request content through OpenRouter to the selected model provider. The privacy notice describes the Google Calendar data accessed, how it is processed and stored, and the owner's choices.
